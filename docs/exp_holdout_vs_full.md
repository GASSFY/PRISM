# 实验：Holdout vs Full（α 选参协议）

比较两种校准协议下的一维 α 搜索（`α=θ2`，`θ1=1−α`），再以下游任务判定协议优劣（**不**用 A/B 的 ΔCE 互比）。

## 设定

| 项 | 值 |
|----|-----|
| 模型 / 校准 / ratio / W4 | 与 Offline 对照实验相同；`ratio=0.01`，`w_group=128` |
| 协议 A（不切开） | 128 条同时做 Hessian/选列与 ΔCE |
| 协议 B（切开） | 96 条 Hessian/选列；32 条 hold-out 只算 ΔCE |
| 搜索 | 每协议 8 次：粗扫 `{0,0.25,0.5,0.75,1.0}` + 邻域 3 点（0.1 网格） |
| 判定 | RealWorldQA + MMMU；两行都保留 |

## 结果

| 协议 | α* | ΔCE（各自校准集） | RWQA exact_match | MMMU mmmu_acc |
|------|-----|-------------------|------------------|---------------|
| **A** 不切开 | **0.30** | 0.019385 | **0.6601** ±0.0171 | **0.4933** |
| **B** 切开 | **1.00** | 0.017556 | **0.6588** ±0.0172 | **0.4933** |

## 结论

下游上 A 略高或持平（RWQA 差 ~0.001，stderr 内；MMMU 相同）。当前证据下 **不切开更简单且不更差**，后续默认采用协议 A。α 搜索不是训练 epoch，而是候选点上的伪量化 + 前向 ΔCE。
