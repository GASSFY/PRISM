# 实验：Ψ ablation（相对显著性）

比较纯 \(K\)（`α=θ2=0`）与加入 Ψ（`α=0.2`，`θ1=1-α`）是否带来稳定下游收益。

## 设定

| 项 | 值 |
|----|-----|
| 模型 | LLaVA-OV-7B、InternVL2-8B |
| 协议 | offline，`r=0.01`，校准 128 |
| α | `{0.0, 0.2}` |
| 评测 | RealWorldQA + MMMU-val |

## 结果（摘要）

| 模型 | α | RWQA | MMMU |
|------|---:|-----:|-----:|
| llava_ov | 0.0 | 0.6667 | 0.4878 |
| llava_ov | 0.2 | 0.6601 | 0.4944 |
| internvl2_8b | 0.0 | 0.6431 | 0.4789 |
| internvl2_8b | 0.2 | 0.6523 | 0.4789 |

## 结论

Ψ **没有跨模型稳定收益**（LLaVA 上 RWQA 反而略降）。因此主路径删除 `ASD=θ1·K+θ2·Ψ`，选列只保留全局归一化 \(K\)（及可选跨模态融合）。
